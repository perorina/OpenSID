# Persona And Ownership

Status: initial scaffold. Needs validation against real village operations.

| Persona | Likely ownership | Core jobs |
|---|---|---|
| Operator data penduduk | Kependudukan | Penduduk, KK, wilayah, peristiwa, data quality |
| Kasi Pelayanan | Surat/layanan | Permohonan, verifikasi, penerbitan, arsip surat |
| Sekdes/Kades | Approval/TTE | Approval, signature, oversight, escalations |
| Admin informasi | Website publik | Artikel, galeri, menu, pengumuman, social media |
| Kaur Keuangan | Keuangan/transparansi | APBDes, laporan, publikasi realisasi |
| Kasi Kesejahteraan | Bantuan/social | Program bantuan, peserta, DTKS-style data |
| Kaur Perencanaan | Pembangunan | Pembangunan, status desa, planning records |
| PPID officer | Informasi publik | PPID, produk hukum, dokumen publik |
| Operator sistem | Technical operation | User, role, backup, restore, plugin, system status |
| Warga | Layanan Mandiri | Profile, request letter, upload documents, messages |

Open question: whether OpenSID UI currently makes these ownership boundaries obvious, or whether all modules appear as one large admin responsibility.
